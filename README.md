- [Download Python 3.9.2](https://www.python.org/ftp/python/3.9.2/python-3.9.2-amd64.exe)

## VIRTUAL ENVIRONMENT
### - Create
`python -m venv virtualenv`

### - Activate
`virtualenv\Scripts\activate`

`pip install django==2.2.19 pyodbc==4.0.30 django-mssql-backend-azure==2.9.2 python-dateutil simplejson pyreportjasper==1.0.2 requests pyOpenSSL pycryptodome cryptography pusher openpyxl python-dotenv bcrypt`
